# Chrome Web Store Listing

## Name
Thadm Browser Bridge

## Short Description (132 chars max)
Connects your browser to Thadm for AI-powered web automation, data sync, and memory capture from authenticated pages.

## Detailed Description
Thadm Browser Bridge connects your browser to the Thadm desktop app, enabling AI-powered tasks to interact with web pages you're logged into.

HOW IT WORKS
This extension connects to Thadm's local server (localhost:3030) via WebSocket. When a Thadm task needs to read data from a web page, it sends a request through the local server to this extension, which executes it in the browser tab where you're already authenticated.

USE CASES
- Sync your ChatGPT and Claude conversation history into Thadm memories
- Extract data from authenticated dashboards and internal tools
- Automate web workflows triggered by your screen activity

PRIVACY & SECURITY
- All communication stays on localhost — no data is sent to external servers
- The extension only activates when Thadm's local server is running
- JavaScript execution is triggered only by your local Thadm tasks
- No tracking, no analytics, no data collection

REQUIREMENTS
- Thadm desktop app running on the same machine
- Works with Chrome, Arc, Brave, Edge, and other Chromium browsers
